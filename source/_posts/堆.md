###### 基础概念
类似于水下的泡泡，总是把最大的泡泡或者最小的泡泡调整到堆顶部，常用的有向下调整和向上调整，两种维护堆序的操作
```C++
    void siftDown(int i) {
        int n = heap.size();
        while (true) {
            int largest = i;
            int left = 2 * i + 1;
            int right = 2 * i + 2;
            if (left < n && heap[left] > heap[largest])
                largest = left;
            if (right < n && heap[right] > heap[largest])
                largest = right;
            if (largest == i) break;
            swap(heap[i], heap[largest]);
            i = largest;
        }

    }
```
向下调整是编号最大的非叶子节点开始向下调整，每次都把检索中的最大值放到当前节点，删除时用
```C++
void siftUp(int i) {
        while (i > 0) {
            int parent = (i - 1) / 2;
            if (heap[parent] >= heap[i]) break;
            swap(heap[parent], heap[i]);
            i = parent;
        }
    }
```
向上调整从当前节点往上比较，把最大值放到父节点，一般插入节点的时候用。
