# 编辑距离
```C++
int left=D[i-1][j]+1;
int right=D[i][j-1]+1;
int same=D[i-1][j-1];
if(word1[i-1]!=word2[j-1])same+=1;
D[i][j]=min(min(left,right),same);
```
> 字符串转换为小字符串，如horse->ros可以看作horse->ro+1，即将原本的转换变成更短一级的字符串，直到两者字符串其中之一为空，这就是DP的边界，一共有像代码所示的三种变换情况，在word2加上word1的第i个字符；在word1加上word2的第j个字符；两者完全对应时，查看第i和位置的字符是否相同，不相同则转换。(Dij 代表word1的1到i字符对应word2的1
> 到j字符)
