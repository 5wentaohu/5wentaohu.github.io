# 前缀和
### 一维前缀和    
```C++
 // 读入数组
    for (int i = 1; i <= n; i++) {      cin >> a[i];
    }
    // 构建前缀和
    for (int i = 1; i <= n; i++) {
        prefix[i] = prefix[i-1] + a[i];
    }
```
即prefix数组相应编号的元素存储着原数组从开始到对应编号的元素和。
### 二维前缀和

 ```C++
   // 读入矩阵（从1开始）

 ```

# 差分数组
### 一维差分数组
```C++
#include <iostream>
using namespace std;
int main() {
    int n, m;
    cin >> n >> m;
	int a[1005] = {0};    // 原数组
    int d[1005] = {0};    // 差分数组 
    // 读入原数组
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }    
    // 构建差分数组
    for (int i = 1; i <= n; i++) {
        d[i] = a[i] - a[i-1];
    }  
    // m次区间修改操作
    while (m--) {
        int l, r, x;
        cin >> l >> r >> x;
        d[l] += x;
        d[r+1] -= x;  // 注意：r+1 <= n，否则需要数组开大一点
    }
    // 对差分数组求前缀和，得到修改后的原数组
    for (int i = 1; i <= n; i++) {
        a[i] = a[i-1] + d[i];
        cout << a[i] << " ";
    }
    return 0;
}
```
**定义**：对于原数组 `a[1..n]`，差分数组 `d[1..n]` 满足：
- `d[1] = a[1]`  
- `d[i] = a[i] - a[i-1]` (2 ≤ i ≤ n)
**核心性质**：对差分数组求前缀和，就能得到原数组
- `a[i] = d[1] + d[2] + ... + d[i]`  
<mark>注意一维差分数组中的m次修改操作</mark>

```C++
        d[x2+1][y2+1] += x;
    }
    // 对差分数组求二维前缀和，得到修改后的原矩阵
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            a[i][j] = a[i-1][j] + a[i][j-1] - a[i-1][j-1] + d[i][j];

    }
```

一些小提示：如果要进行区间修改，一定要先进行计算差分数组，因为如果不计算的话，在额外添加数值比如砖块的时候，会把自身加入，导致多算。
#### 一些练习
```C++
int main() {
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> x >> c;
        if (c == 'L') {
           d[now - x + 1]++;
            d[now + 1]--;
            now = now - x + 1;
        } else {
            d[now]++;
           d[now + x]--;
            now = now + x - 1;
        }
    }
    int cur = 0, last = 0, ans = 0;
    for (auto &p : d) {
        if (cur % 4 == 1) ans += p.first - last;
        cur += p.second;
        last = p.first;
    }
    cout << ans;
```
这里用map d来存储每一个产生变化的拨动变化起始位置，第一个元素为坐标，第二个元素为波动变化次数
last为上一起始位置，p.first - last 这个区间内的拨动值都是一样的因为两者都是拨动变化起始位置，cur是
前缀和的体现，每一次都加上拨动次数的变化，即代表着一段区间内的拨动次数。
