##### 关于左中位数和右中位数的选择
如果是寻找第一个满足的则采用左中位数，即right=mid，left=mid+1，mid=left+(right-left)/2；因为在这种条件下，若mid满足条件，那么我们需要向左边寻找，即用right来保留mid的值然后继续比对前面的区间。
如果是寻找最后一个满足的则采用右中位数，即left=mid，right=mid-1，mid=left+(right-left+1)/2；因为在这种条件下，若mid满足条件h，那么我们需要向右边寻找，即用left来保留mid的值然后继续比对后面的区间。
##### 二分答案
	若答案可能在1到10中，那么可以尝试5是否是答案，接着继续二分下去，接下来继续二分。
	以序列字段和例
```C++
#include <bits/stdc++.h>
using namespace std;
vector<long long> A;
long long N, M;
bool check(long long mid)
{
    long long count = 1;
    long long sum = 0;
    for (long long i = 1; i <= N; i++)
    {
        sum+=A[i];
        if(sum>mid)
        {
            count++;sum=A[i];
        }
    }
    return count <= M;
}  
int main()
{
    cin >> N >> M;
    A.resize(N + 1);
    long long left = 0, sum = 0;
    for (long long i = 1; i <= N; i++)
    {
        cin >> A[i];
        left = max(left, A[i]);
        sum += A[i];
    }
    long long right = sum;
    while (left < right)
    {
        long long mid = left + (right - left) / 2;
        if (check(mid)) right = mid;
       else left = mid + 1;
    }
    cout << left << endl;
    return 0;
}
```
###### 子序列平均最大值
```C++
#include<bits/stdc++.h>
using namespace std;
int a[100001];double b[100001];
const double eps=1e-3;double ans;
double sum[100001];int q[100001];
int n;int S,T;
bool check(double mid)
{
    int i,l=1,r=0;
    for(i=1;i<=n;i++)
    {

        b[i]=(double)a[i]-mid;
    }
    sum[0]=0;
    for(i=1;i<=n;i++)
    {
        sum[i]=sum[i-1]+b[i];
    }
    for(int i=0;i<=n;i++)
    {
        if(i>=S)
        {
            while(r>=l&&sum[i-S]<sum[q[r]])--r;
	        q[++r]=i-S;
        }
        if(r>=l&&q[l]<i-T)++l;
        if(r>=l&&sum[q[l]]<=sum[i])return true;
    }
    return false;
}
```
检查逻辑是先将目标数组减去候选的mid值，将求平均值转化为求子序列的和，
第二步对处理过的数组进行前缀求和，这时将求和转化为sum[r]-sum[l]>=0;
因为题目要求子序列长度为[S,T],所以第三步，固定右端点r，并维护一个单调队列
来寻找对应右端点的最小左端点。
